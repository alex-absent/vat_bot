# VAT TAX FREE Telegram Bot

Telegram-бот для сканирования, проверки и отслеживания статусов возврата налога (TAX FREE / VAT) по фотографиям чеков или по номеру документа.

---

## Основные возможности

- **Гибридное распознавание чеков по фото (Barcode + OCR):** мгновенное считывание штрихкода **Code 128** с фотографии чека и многоступенчатое текстовое распознавание (OCR) с автоматической коррекцией ориентации (EXIF) и восстановлением префикса.
- **Проверка статуса онлайн:** мгновенный запрос актуального статуса возврата по номеру документа (через команду `/vat`, кнопку меню или ручной ввод).
- **Сохранение и учёт документов:** привязка сохранённых номеров к `user_id` пользователя в локальном журнале `saved_vat.log` без дубликатов.
- **Массовое обновление статусов:** последовательная проверка всех активных документов пользователя (кроме тех, по которым возврат уже выплачен) с визуальным прогресс-баром и автоматической перезаписью статусов в базе.
- **Управление записями:** просмотр последних сохранённых номеров и полная очистка истории пользователя в один клик.

## Алгоритм распознавания (`ocr.py`)

Для максимальной скорости и точности извлечения номера документа (`extract_taxfree_number`) применяется каскадная обработка изображения с предварительным выравниванием по EXIF-тегам:

1. **Декодирование штрихкода (Code 128):** быстрое чтение линейного штрихкода через `zxing-cpp` (в оригинале, градациях серого и с автоконтрастом).
2. **Сканирование зоны наклейки:** прицельное распознавание нижней области документа через Tesseract (`--psm 7`) с адаптивным масштабированием.
3. **Полностраничный OCR:** бинаризация и распознавание всего листа документа (`pol+eng`, `--psm 6`).
4. **Сканирование верхней части документа:** резервная проверка верхних 40% чека.
5. **Нормализация номера:** очистка пробелов и дефисов, замена частых ошибок OCR (`O` → `0`) и автоматическое восстановление префикса `26PL00` для коротких номеров вида `TF...`.

## Формат хранения данных (`saved_vat.log`)

Каждая запись хранится в отдельной строке в кодировке `UTF-8` с разделителем `;`:

```text
YYYY-MM-DD HH:MM:SS;USER_ID;VAT_NUMBER;STATUS
```

### Особенности реализации
- **Экранирование переносов строк:** символы `\n` внутри статуса заменяются на `\\n`, а `;` — на `,`, чтобы многострочные ответы не нарушали структуру файла.
- **Потокобезопасность:** все операции чтения, добавления, обновления и удаления защищены асинхронной блокировкой `asyncio.Lock()`.
- **Валидация номеров:** поддерживаются форматы вида `26PL00TF003976030` и `TF003976030` (проверка регулярным выражением `^(\d{2}PL00)?TF\d+$`).

## Установка и запуск

### 1. Требования
- Python 3.10 или выше
- Установленный движок **Tesseract OCR** в системе (с языковыми пакетами `eng` и `pol`)
- Python-библиотеки: `python-telegram-bot` (20.x+), `zxing-cpp`, `pytesseract`, `Pillow`

### 2. Установка зависимостей
```bash
pip install python-telegram-bot zxing-cpp pytesseract Pillow
```

### 3. Настройка конфигурации
Создайте файл `config.py` в корневой директории проекта и укажите токен вашего Telegram-бота, полученный от `@BotFather`:

```python
BOT_TOKEN = "ваш_токен_бота"
```

### 4. Запуск бота
```bash
python bot.py
```

## Команды и интерфейс бота

### Команды меню
- `/start` — запуск бота и отображение главного меню.
- `/vat <номер>` — быстрая проверка статуса без сохранения (пример: `/vat 26PL00TF003976030`).

### Кнопки главного меню
- **📷 Сканировать VAT** — инструкция по отправке фотографии документа для распознавания.
- **📋 Мои номера** — вывод списка сохранённых документов пользователя (до 20 последних записей) с датой и текущим статусом.
- **🔍 Проверить номер** — запрос номера документа для ручного ввода текстом.
- **🔄 Обновить статусы** — проверка актуальных статусов по всем документам, не имеющим статус `💰 Возврат выплачен`, с сохранением изменений в `saved_vat.log`.
- **🗑 Удалить все записи** — удаление всех сохранённых номеров текущего пользователя.
